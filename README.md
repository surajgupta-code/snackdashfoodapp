

# 🍔 Snack Dash

**Snack Dash** is a high-performance food ordering web application built with the **MERN** stack philosophy (React, Redux, Tailwind). Inspired by Swiggy, it provides a seamless user experience for browsing restaurants, searching for favorite cuisines, and managing a real-time shopping cart.

Developed by **Suraj Gupta** 🚀

---

## 🚀 Overview

* **Dynamic UI:** A responsive food delivery interface built using **React** and **Tailwind CSS**.
* **Live Data:** Integrated with **Swiggy’s API** to fetch and display real-time restaurant listings and menus.
* **State Management:** Powered by **Redux Toolkit** for predictable and efficient data flow across the app.
* **User-Centric:** Features a robust search engine, category filtering, and a fully functional cart system.

---

## ✨ Key Features

| Feature | Description |
| --- | --- |
| **Live API Fetching** | Fetches real-time restaurant data based on location. |
| **Search & Filter** | Instant search for restaurants and dishes with high-speed filtering. |
| **Cart System** | Persistent cart management using Redux (Add/Remove/Clear items). |
| **User Auth** | Secure login functionality for a personalized experience. |
| **Responsive Design** | Optimized for mobile, tablet, and desktop screens using Tailwind. |

---

## 🛠️ Technical Details & Highlights

* **Custom Hooks:** Implemented custom hooks for fetching data and tracking online status to keep components clean and modular.
* **Optimization:** Used **React Router** for seamless navigation and **Lazy Loading** to optimize the bundle size.
* **Conflict Management:** Handled CORS issues during API integration to ensure smooth data flow from the Swiggy live endpoint.
* **UI/UX:** Utilized **Tailwind CSS** for a modern, mobile-first design and implemented a Shimmer UI for better user retention during loading states.

1. **Clone the repo**
```bash

```


2. **Install dependencies**
```bash
npm install

```


3. **Run the app**
```bash
npm start

```
